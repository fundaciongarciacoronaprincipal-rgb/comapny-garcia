Resumen

1. Identificar al alumno

Escanea la matrícula del alumno para consultar sus datos registrados.

Matrícula del alumno

Puedes escanear la matrícula con el lector USB. Si el lector envía Enter automáticamente, la búsqueda se realizará sola.

Preparando cámara...

Coloca la matrícula dentro del marco. La cámara leerá el código automáticamente cuando pueda reconocerlo.

Datos del alumno

2. Identificar al docente

Escanea el código del docente. Se utilizarán los últimos nueve dígitos numéricos para consultar el registro.

Número de servidor

Se ignoran los caracteres que no sean números y se toman los últimos nueve dígitos.

Preparando cámara...

Centra el código del docente en el marco de lectura.

Datos del docente

3. Identificar el libro

Escanea el código de barras o QR del libro para localizarlo en el inventario.

Código del libro

El código del libro se consulta tal como se lee, incluyendo letras o símbolos si los contiene.

Preparando cámara...

Coloca el código del libro dentro del marco y espera a que la cámara lo reconozca.

Datos del libro

4. Confirmar préstamo

Revisa que la información del alumno, docente y libro sea correcta antes de guardar el registro.

Al confirmar, se intentará registrar el préstamo en la tabla prestamos de Supabase.
